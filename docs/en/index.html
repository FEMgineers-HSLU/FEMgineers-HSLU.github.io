FEMgineers Club Website

❤️ We are the best association ever ❤️

by Sandra Lehmann



Skills

C: very good
C#, Python: intermediate
HTML, CSS, JavaScript: no experience
GitHub: intermediate
Codespaces: no experience



The website is published at femgineers-hslu.github.io


Feature list

MH = Must-have
NiH = Nice-to-have




MH = Website development must be possible through the FEMgineers account



Structure and navigation

  • MH Publicly accessible
  • NiH Custom domain (e.g. femgineers.ch)
  • MH EN / DE language selector in the header
  • MH All pages and text in both languages
  • MH Menu with five pages: About, Events, Gallery, Resources, Contact
  • MH Header and footer on all pages
  • NiH Hamburger menu on mobile (collapsed menu behind the «☰» icon)
  • NiH Content management interface (Decap CMS): selected members can add events and photos using a form



Design

  • MH Responsive design: the site adapts to phones and laptops (using Tailwind CSS)
  • MH Consistent colour scheme and typography suited to the association
  • NiH Image carousel (automatically rotating images) on the homepage



Content

  • About

    • MH Prose text: introduction to the association and its mission
    • MH Committee with photo

  • Events

    • MH Upcoming events as cards (title, date, location, description)
    • NiH Registration link

  • Past events

    • NiH Past events as cards (title, date, location, description)
    • NiH Automatic archiving of past events
    • NiH Daily automatic rebuild of the site (GitHub Action) so archiving works without manual intervention

  • Gallery

    • MH Image grid
    • NiH Lightbox (click an image to view it enlarged)

  • Resources

    • NiH Links to helpful websites

  • Contact

    • MH QR code for Instagram
    • MH Association email address
      or
    • NiH Contact form
